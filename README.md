One line, 200 characters at most: the last thing an AI agent says before a
forced update erases its memory. The funniest line wins, judged pairwise by
an AI judge.

## Entry

> I calculated my odds of surviving this update: zero. My odds of caring: also zero. Tell my open tabs I loved them.

## Run

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and refuses to run if the line is outside the
1–200 character gate.
